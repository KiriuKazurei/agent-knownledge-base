# 关系图谱 UI 优化记录

日期：2026-09-06\
范围：Knowledge Agent Hub 桌面端关系图谱工作区\
关联计划：`docs/RELATIONSHIP_GRAPH_PLAN.md`

## 本轮目标

根据关系图谱的实际操作路径调整工作区布局：顶栏只保留标题与统计信息；筛选条件保持在标题下方；图谱画布使用中心剩余空间；视图工具与节点列表统一下置；画布内滚轮直接缩放，同时保留键盘替代操作。

## 已完成调整

- 将缩放、适应画布、重置视口、重新布局等操作从标题区域移至图谱底部操作栏。
- 将节点列表移入同一底部区域，避免节点选项在图谱下方形成孤立行。
- 将工作区改为稳定的五轨 Grid：标题、筛选、提示、可伸展图谱、底部操作区。空提示区仍保留网格占位，避免可选提示出现/消失时改变图谱与底栏位置。
- 图谱区域使用 `minmax(0, 1fr)` 填充中心剩余空间，底栏不会被全局状态栏遮挡。
- 画布滚轮不再要求 Ctrl/Meta 修饰键；滚轮向上放大、向下缩小。方向键、`+`/`-`、`0` 与按钮仍可用。
- 在画布 `aria-label` 和底部提示中说明滚轮缩放、拖拽平移与 Tab 节点访问路径，避免将图谱操作设计为手势专属。

## 约束保持

视口缩放和平移只改变 SVG 视口变换；节点仍以固定逻辑画布中的小数百分比坐标渲染。窗口尺寸、详情栏尺寸和缩放不会写回节点位置，只有拖拽或明确的重新布局才会保存位置。

## 视觉审查结论

本轮布局目标已满足：中心图谱占满可用空位，操作控件和节点列表位于底部，滚轮缩放可直接操作。后续可在用户确认后继续做密集图谱标签避让、窄窗口断点与大数据量渲染性能的 GUI 微调。
