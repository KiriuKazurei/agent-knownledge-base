# 图谱工作区空库引导修复（2026-09-08）

## 问题

在新的隔离数据根中没有任何知识库时，点击“关系图谱”不会有图谱可初始化。组件会提前返回“请选择知识库”，但缺少明确的下一步，容易被认为是工作区切换没有响应。

## 修复

- 空库情况下仍渲染带“关系图谱”标题的完整工作区。
- 提供明确说明，以及“新建知识库”和“返回知识管理”两个操作。
- 图谱内的新建操作使用独立无障碍名称，避免与侧栏的新建按钮冲突。
- 已选知识库的图谱加载、位置保存与键盘交互路径未改变。

## 连通性门禁

- App 工作区导航的空库测试验证：关系图谱按钮 → 图谱空状态 → 图谱内新建知识库按钮 → 新建知识库对话框。
- 已选知识库的关系图谱测试验证：导航 → 图谱工作区 → 图谱数据请求与详情面板。
- 实际 Electron 验收实例已记录 Vite HMR 更新 `RelationshipGraph.tsx` 与 `styles.css`；API 与渲染器在该实例中均已就绪。

## 结论

这不是图谱初始化异常。空知识库现在有清晰、可继续的工作区状态；选择或创建知识库后，图谱才会请求该库的稳定知识关系。
